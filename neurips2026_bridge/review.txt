TL;DR: We propose an end-to-end framework that jointly models sequential and relational user behavior by integrating sequence models with graph models, achieving better performance than using either paradigm alone.
Abstract:
Modeling user behavior has become a core component in industrial applications across a wide range of domains, including e-commerce, social media, health, finance, cybersecurity, streaming platforms, and online gaming. User behaviors inherently consist of both sequential and relational components. Typically, they are represented as sequences of events for each user, such as logging in, visiting pages, viewing products, etc; forming a collection of sequential samples. In addition, other aspects of user behavior form relational information, such as friendships, family ties, or device sharing among users. Traditionally, practitioners modeling user behaviors must choose between two paradigms: treating the data as independent sequences via sequential models, or forcing all information into a graph representation and training a graph model on top of it. We propose that, instead of picking just one paradigm, we represent inherently sequential behavior using a sequence model and incorporate this into a graph model to capture the relational aspects of user behavior. To achieve this, we introduce an end-to-end training framework that jointly optimizes both components. We demonstrate that this unified approach improves model performance compared to relying on graph-only methods, sequence/text-only methods, or two-stage sequence-graph models, where applicable.

Summary:
This paper proposes BRIDGE, an end-to-end framework for modeling user behavior by combining user’s event sequences with user-to-user relationship graphs. The model first uses a Transformer to learn a representation of each user’s event history, then compresses this representation into a user embedding and passes it to a graph neural network to incorporate information from related users. The authors evaluate the model on relationship prediction and fraud detection tasks using several real-world datasets. Their results show that combining sequential and relational information through end-to-end training performs better than using only sequence models, only graph models, or training the two components separately.

Summary
The paper proposes BRIDGE, an end-to-end framework designed to jointly model user behavior by integrating sequential event data (via Transformers) and static relational data (via Graph Neural Networks). To overcome the loss of temporal granularity associated with pooling sequences into static node embeddings, the authors introduce TOKENXATTN, a novel token-level cross-attention mechanism. This layer enables fine-grained, event-to-event message passing between neighboring sequences across the graph topology. The authors evaluate their framework on relationship prediction and fraud detection tasks, demonstrating performance improvements over static GNNs, temporal graph models, and two-stage sequence-graph baselines.

Strengths
The paper addresses a highly significant and ubiquitous problem: effectively jointly modeling sequential personal events and static relational graphs for user behavior modeling, which has broad applications in e-commerce, fraud detection, and social media.

The proposed TOKENXATTN mechanism introduces a highly novel architectural contribution. By allowing direct cross-attention between uncompressed sequences of neighboring nodes during message passing, the model elegantly preserves temporal fidelity and avoids the signal dilution common in standard GNNs.

The framework demonstrates robust empirical performance gains over a wide range of baselines, effectively addressing a major operational bottleneck in industrial settings where practitioners frequently rely on sub-optimal two-stage decoupled pipelines.

Weaknesses
The conceptual claim that end-to-end joint training of sequence and graph modalities outperforms decoupled two-stage pipelines is already established in the literature. The authors might consider better contextualizing their empirical gains against prior works that have successfully unified sequential patterns with GNNs (Reference Paper: Sequence-Graph Duality: Unifying User Modeling with Self-Attention for Sequential Recommendation, 2022) (Reference Paper: End-to-End Graph-Sequential Representation Learning for Accurate Recommendations, 2024) (Reference Paper: Set-Sequence-Graph: A Multi-View Approach Towards Exploiting Reviews for Recommendation, 2021).

The relationship prediction task on the Amazon datasets appears to suffer from target leakage. The ground-truth graph is constructed by connecting users who co-reviewed at least three products, while the input sequences explicitly include product IDs. This allows sequence-aware models to deterministically predict edges simply by comparing input sequences, rendering comparisons against graph-only models (which lack sequence access) unfair. Please consider reformulating the input features or the target definition to prevent this leakage.

The paper claims improvements over 'strictly sequence-only' methods, but no supervised sequence-only baseline is evaluated for the relationship prediction task. Furthermore, the Two-Stage baselines use frozen sequence embeddings pre-trained via an unsupervised objective, whereas BRIDGE optimizes the sequence encoder end-to-end with a supervised objective. This conflates the architectural benefit of joint modeling with the advantages of supervised representation learning. Including a baseline with a supervised sequence model (without graph components) would better isolate the contribution.

To adapt static relationship edges for temporal graph baselines, the experimental setup assigns random timestamps within the users' event timelines. Injecting random temporal noise disrupts the ordering and causality these architectures rely on, artificially weakening these baselines. The authors might want to acknowledge this limitation explicitly or explore fairer adaptation strategies.

There is a lack of feature parity in the Fraud Detection baselines. BRIDGE and Temporal Graph models receive a 'learnable rating embedding', but the descriptions for the 'Text Embedding Model' and 'Static Graph + Text Embedding' baselines do not mention the inclusion of user ratings. Denying this highly correlated feature to certain baselines confounds the evaluation.

For the Fraud Detection task, the paper reports 'Max F1' by finding the best F1 metric across thresholds. If this threshold tuning is performed directly on the test set, it constitutes data leakage and yields overly optimistic performance estimates. The classification threshold should be calibrated on a separate validation set and then applied fixedly to the test set.

The TOKENXATTN mechanism scales quadratically with sequence length, but the specific sequence lengths and truncation strategies employed in the experiments are not explicitly reported. If sequences were heavily truncated to fit into GPU memory, this could explain why a very small compression length (Lc=4) was found to be sufficient in the BRIDGE-GCN ablations. Please clarify the sequence length configurations.

There are mathematical and descriptive inconsistencies in the algorithms. Algorithm 1 compresses sequence representations before message passing, which contradicts the TOKENXATTN architecture described in Section 4.2 that operates on uncompressed sequences. Additionally, Algorithm 2 contains a redundant scaling factor for mean aggregation, leading to an unintended double-normalization of 1/|N(i)|^2. Please revise the pseudocode to match the text descriptions.
